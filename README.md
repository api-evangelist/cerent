# Cerent

Cerent Corporation was a Petaluma, California optical-networking startup, founded in the mid-1990s and backed by Kleiner Perkins, that built the Cerent 454 — a compact next-generation SONET multiservice provisioning platform that collapsed traditional add-drop multiplexing into a far smaller, cheaper, data-aware box for carrier metro networks.

Cisco Systems acquired Cerent in 1999 for approximately $6.9 billion in stock, at the time the largest acquisition in Cisco's history. The product line shipped on as the Cisco ONS 15454, one of Cisco's most successful optical transport platforms.

**Status:** acquired (Cisco Systems, 1999). Not an active API provider.

Cerent's hardware-era business predated public web APIs entirely, and it maintains no developer platform, documentation, SDKs, or API surface today. As of 2026-07-20, `cerent.com` is delegated to Cisco nameservers with no A/MX/TXT records, and `www.cerent.com` redirects to Cisco's acquisition-notice page. No provider artifacts have been created for this profile — there is nothing to harvest.

This profile is retained as a venture-portfolio historical record.
